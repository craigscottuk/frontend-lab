# Personal organiser: DaisyUI foundation

This is an independent Next.js App Router, TypeScript, and Tailwind CSS application. DaisyUI 5 is installed as a Tailwind plugin through `@plugin "daisyui"` in `src/app/globals.css`. The screen is still the Next.js starter.

Run `npm ci` and `npm run dev -- --port 3001` from this directory. Verify changes with `npx tsc --noEmit`, `npm run lint`, and `npm run build`.

No shadcn/ui or assistant-ui packages are used in this application.
